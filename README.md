# git

Meltrui 的项目仓库。

## 开始使用

克隆仓库：

```bash
git clone https://github.com/Meltrui/git.git
cd git
```

## 目录结构

```
.
├── .gitignore
├── LICENSE
└── README.md
```

## 贡献

1. 新建分支：`git checkout -b feature/your-feature`
2. 提交改动：`git commit -m "feat: 你的改动"`
3. 推送分支：`git push origin feature/your-feature`
4. 创建 Pull Request
